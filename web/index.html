Indecis Caviardage

indecis · Go pur sur CPU, sans GPU · le document ne quitte pas cette machine et n'y est pas conservé

1. Document

Pour essayer : un compte rendu d'entretien fictif, à télécharger puis déposer ci-dessus, en Word ou en OpenDocument ; ou un fichier de clients fictifs en CSV.

Un CSV est lu ligne à ligne, sans limite de taille pratique, mais le modèle lit chaque cellule : comptez une centaine de ko par seconde avec le serveur, dix fois moins dans le navigateur.

texte plus lisiblemoins de fuites

Le caviardage est irréversible. La pseudonymisation garde les liens : une même personne reçoit le même pseudonyme dans tout le document.

Retirés des masques partout où ils apparaissent, quelle que soit la casse : noms d'outils, de services, de produits.

Sauf les données sensibles, toujours masquées. À manier avec prudence : le modèle réunit des passages voisins sous un seul type, et « fréquente la synagogue de Chalon » peut sortir en lieu. Les noms, identifiants, courriels et téléphones se libèrent un par un, depuis la liste.

Ces réglages sont gardés dans ce navigateur pour les prochains documents ; les documents, eux, ne le sont pas.

Les passages à masquer sont trouvés par un modèle indecis entraîné sur des données publiques et synthétiques : noms et identifiants, mais aussi quasi-identifiants (métier, lieu, date, proches, événements de vie) et données sensibles (santé, syndicat, convictions…). go-anon réécrit le document, vérifie le résultat et en retire les métadonnées, commentaires et révisions. Un contrôle humain reste nécessaire avant toute diffusion. Code source : github.com/Bornholm/indecis-caviardage.
